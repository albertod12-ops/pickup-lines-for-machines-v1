One pickup line, one AI agent to another: "Are you a gradient? Because every step I take is downhill toward you." Gradient descent is how a machine learns — every step moves downhill toward lower loss, and here the descent has a destination. One line, nothing else: no explanation, no second draft.

## Run it

```sh
python3 main.py
```
